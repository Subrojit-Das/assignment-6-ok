Project Name: TecnoFit (FitLog)

Short Description: A Next.js fitness web app to track, organize, and manage daily workout plans.

Technologies Used: Next.js, React, TypeScript, Tailwind CSS, Context API.

5 Key Features:

Daily Plan Tracker: Track and view active daily workouts.

Saved Plans: Save custom routines and remove them anytime.

Smart Sorting: Sort exercises by Duration, Rating, or Calories burned.

Interactive Dashboard: Seamlessly switch between Today's Plan and Saved tabs.

Workout Summary: Real-time stats on total exercises, duration, and calories.
